航线经营

读取销售数据，形成航线策略

识别主卖、高价和放量窗口，把经验判断转化为可回看的策略结果。

销售节奏

按起飞周期组织动作

围绕 D-N 到 D-1 的窗口安排价格、放量和复盘。

风险控制

跟踪成本、售价与库存

在执行前识别库存压力、价格风险和保护边界。

人工确认

AI 给建议，人决定是否执行

策略进入任务池后必须经过人工确认，避免自动改动真实业务。

一条可追踪的验证路径

读取数据

销售文件、系统已有数据或本地 Excel 建立分析基础。

形成策略

输出销售窗口、库存风险、价格建议和执行条件。

人工确认

任何执行动作都先由用户确认，保留操作边界。

隔离验证

通过 Mock OTA 检查政策、订单、取消和库存回流。
