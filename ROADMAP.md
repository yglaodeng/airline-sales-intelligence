# Roadmap

This roadmap describes public, testable work. It does not promise production OTA integration.

## Near term

- Expand synthetic route scenarios for inventory and pricing-window tests.
- Document the strategy-to-approval-to-Mock-OTA workflow with a reproducible example.
- Improve installation diagnostics for first-time local users.

## Later, after separate security review

- Define adapter contracts for external distribution channels without including credentials.
- Add deployment guidance for isolated demo environments.
- Evaluate additional revenue-management models against documented synthetic fixtures.

## Out of scope for the public prototype

- Real customer, order, inventory, payment, or ticketing data.
- Autonomous production pricing or inventory changes.
- Claims of live OTA connectivity without platform-side verification.
